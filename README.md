# 🛡️ Aegis Stream

**Unified Task-Communication Platform**

Aegis Stream integrates video meetings, task management, AI intelligence, and security tagging into a single pane of glass.

## ✨ Features

- **Unified Task-Meeting View** — Semi-transparent task board overlay during video calls
- **Identity Tags** — Blue (Core Team) / Amber (Guest) security badges
- **AI Pulse Intelligence** — Live scriber, decision highlights, contextual recall
- **Enhanced Video Core** — Interactive co-op screen sharing, smart breakout rooms
- **Workflow Automation** — Initiate → Tag → Execute → Review loop

## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 📁 Tech Stack

- Vite (Vanilla JS)
- HTML5 / CSS3 (Glassmorphism dark-mode UI)
- No framework dependencies
